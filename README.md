# 📐 Algoritmos de Álgebra Linear em Python

Durante meus estudos em Álgebra Linear, baseado nas aulas da <abbr title="Universidade Federal Rural do Rio de Janeiro" style="text-decoration: none">UFRRJ</abbr>, desenvolvi códigos em Python para aplicar os algoritmos vistos em sala de aula. 

Com este projeto, busco entender mais o poder da linguagem para aplicações na matemática, além de consolidar os tópicos fundamentais de Álgebra Linear, área presente em diversos setores da Computação - como por exemplo, treinamento de IAs e criação de projetos de Computação Gráfica.

## 📌 Algoritmos implementados

- **Operações com vetores:** soma, produto, normas, módulo, etc
- **Operações com matrizes:** inversa, transposta, adjunta, cálculo de cofatores, etc  
- **Fatoração de matrizes (em desenvolvimento):** Fatoração QR, Fatoração LU, etc
- **Escalonamento de sistemas (em desenvolvimento):**:
- **Métodos iterativos para resolução de sistemas (em desenvolvimento):**: Jacobi, Gauss-Seidel, etc

## 💻 Tecnologias utilizadas

- **Python:** linguagem de implementação simples e altamente legível, que permitiu que os algoritmos fossem melhor escritos e testados
- **NumPy:** biblioteca focada em otimização de operações e manipulação de vetores/matrizes, essencial para a construção dos códigos

## 🚀 Como Executar

1. **Clone o repositório:**

```bash
git clone "https://github.com/samuelsilva07/algebra-linear-python.git"
cd local-do-repositorio
```

2. **Instale as dependências do projeto:**

```bash
pip install -r requirements.txt
```

3. **Escolha um dos algoritmos e execute-o:**

```bash
python pasta/nome_arquivo.py
```

**Dica:** utilize os códigos em aplicações matemáticas para obter os resultados necessários! 😉
